# RadishOS
A x86_64 operating system made from scratch.
I do it for learning.

![screenshot](screenshots/image.png)

## Features
- Framebuffer output
- Serial output
- VFS
- USTAR
- TMPFS
- Heap allocator
- 4-level paging
