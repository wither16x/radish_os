# RadishOS
*Note: screenshots and informations in this README are up to date with THE LAST RELEASE.*

A x86_64 operating system made from scratch that I am making for learning purposes and for fun.

![screenshot](screenshots/image.png)

## Features
- Userspace and syscalls
- ELF64 loader
- PIT driver
- 8259 PIC driver
- Preemptive multitasking
- Framebuffer output
- Serial output
- VFS
- USTAR
- TMPFS
- Heap allocator
- 4-level paging

## Build
First, make sure that the following dependencies are installed on your system:
- `xorriso`
- `nasm`
- `clang` and `clang++`
- `ld.lld`
- `make`
If any dependency is missing in the list above, please let me know!

Next, if you simply want to compile the operating system, run:
```sh
chmod +x scripts/build.sh
./scripts/build.sh
```
Otherwie, if you want to see the valid stack trace in case a kernel panic occurs, run:
```sh
chmod +x scripts/symbols.sh
chmod +x scripts/build.sh

./scripts/symbols.sh
./scripts/build.sh
./scripts/symbols.sh
```
This will compile the kernel and the userspace programs and also copy everything needed in the initrd and compress it.

## Run
You can try RadishOS in an emulator like qemu, or run it on real hardware.
To emulate it in qemu, run:
```sh
qemu-system-x86_64 -cdrom images/radish_os.img -m 2G # or another value
```
**WARNING**: RadishOS has not been tested on real hardware yet!
