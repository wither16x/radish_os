# RadishOS
*Note: screenshots and informations in this README are up to date with THE LAST RELEASE.*

A x86_64 operating system made from scratch that I am making for learning purposes and for fun.

![screenshot](screenshots/image.png)

## Features
- Framebuffer output
- Serial output
- VFS
- USTAR
- TMPFS
- Heap allocator
- 4-level paging

## Build
Run `scripts/build.sh` to compile the kernel, generate an initrd and an ISO.

## Run
You can try RadishOS in an emulator like qemu, or run it on real hardware.
